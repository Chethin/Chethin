I'm a software engineer working on **[papersetter.io](https://papersetter.io)** — an AI-powered exam platform.
I studied Advanced Computing (First Class Honours) at ANU, where my research lived at the
bottom of the stack: compilers, search engines, and the caching tricks that make slow things fast.

Lately I've been pulled to the opposite end — **Three.js, WebGPU, anything where the goal is
making pixels that feel alive.** I like living in both places.
